# Sanad Freelance Radar

أنشئ تطبيق ويب متكامل باسم "رادار فرص المحاسبة" (Accounting Gig Radar) مخصص للمحاسب المستقل (أحمد المدني).

المميزات الأساسية للتطبيق:
1. لوحة تحكم تفاعلية (Dashboard) باللغة العربية لعرض ومتابعة أحدث طلبات ومشاريع المحاسبة والمالية من منصات العمل الحر العربية (مثل مستقل، خمسات، بعيد، وغيرها).
2. واجهة إعدادات التنبيهات مع ربط بوت تليجرام (Telegram Bot Integration): إمكانية إدخال معرف الشات أو التوكن، واختيار الكلمات المفتاحية (مثل: مسك دفاتر، قوائم مالية، زكاة وضريبة، إكسل مالي، قيود محاسبية، تدقيق، دراسة جدوى).
3. مولد عروض التقديم الذكي (AI Proposal Generator): بضغطة زر لكل فرصة، يتم توليد صيغة عرض احترافية ومقنعة مخصصة للمشروع وموجهة لصاحب العمل، مع إمكانية نسخها فوراً.
4. فلترة وبحث متقدم للفرص: تصنيف حسب الميزانية، المهارة المطلوبة (دفاتر، ضرائب، إكسل، برامج ERP كـ قيود وفودكس ودفترة وساب)، ومستوى الإلحاح.
5. صفحة محاكاة / تغذية مباشرة (Live Opportunities Feed) تحتوي على نماذج واقعية ومحدثة للمشاريع المعروضة، مع إمكانية إضافة روابط RSS أو Webhook.
6. واجهة عصرية وسهلة الاستخدام باللغة العربية تدعم الوضعين الفاتح والداكن (Tailwind, RTL).
